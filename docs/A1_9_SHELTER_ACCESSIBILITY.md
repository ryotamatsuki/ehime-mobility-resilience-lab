# A1.9 — 大洲市 避難所 Accessibility

## 目的

A1.9は、A1.8までの病院Accessibilityに加え、大洲市が公式オープンデータとして公開する次の3種類の避難先への公共交通・徒歩Accessibilityを実計算する。

- 指定緊急避難場所
- 指定一般避難所
- 指定福祉避難所

A1.7の終日時間帯レジリエンス、A1.8のRoute / Trip Criticality、A1.6の徒歩乗換、A1.5の病院公式照合Gateは維持する。

- 公開ページ: https://www.city.ozu.ehime.jp/site/opendata/31903.html
- 利用ファイル: https://www.city.ozu.ehime.jp/uploaded/attachment/47130.xlsx

|---|---:|
| 指定緊急避難場所 | 60 |
| 指定一般避難所 | 96 |
| 指定福祉避難所 | 20 |

公式Excelには施設名、住所、収容人数等は含まれるが、緯度・経度は含まれない。

## 位置付与Gate

A1.9では住所を外部ジオコーダーへ自動送信して座標化しない。また、名称や住所から推測座標を作らない。

施設位置は、現在の「ぐるりんおおず」GTFS分析範囲内にあるOpenStreetMapのnamed featureと公式施設名を照合し、次を満たすものだけ利用する。

1. 名称が完全一致、包含一致、または高い名称類似度を持つ。
2. 一意性が確保され、同程度の候補が複数ある場合は除外する。
3. OSM位置を徒歩道路ネットワークへ0.5km以内でsnapできる。
4. 未照合・曖昧・snap不能な施設を勝手に補完しない。

このため、公式属性はA、OSM位置はB、Accessibility計算はC、右回り運休条件はDとして扱う。

## 位置照合結果

2026-08-23時点の実データCIでは、現在のGTFS分析範囲で厳格に位置を確定できた施設は次のとおりだった。

| 種類 | 市全体公式件数 | 現分析範囲でOSM位置まで厳格照合・snapできた件数 |
|---|---:|---:|
| 指定緊急避難場所 | 60 | 4 |
| 指定一般避難所 | 96 | 13 |
| 指定福祉避難所 | 20 | 2 |
| 合計 | 176 | 19 |

重要: 4/60、13/96、2/20を「分析範囲内の照合率」と解釈してはならない。公式Excelには座標がないため、市全体公式件数のうち何件がGTFS分析範囲内に存在するかを公式データだけから判定できない。ここで示す19件は「現在の分析範囲において、OSM named featureとの厳格照合を通過した件数」である。

## 位置品質

照合品質は次の区分を内部QAに保持する。

- `exact`: 公式名とOSM名が正規化後に一致
- `name_equivalent`: 市立・県立等の表記差、ふりがな混入等を含む実質同一名称
- `parent_feature`: 公式避難先が「○○高校運動場」等で、OSM上は親施設「○○高校」の位置を使用

`parent_feature`は施設の所在地確認には有効だが、運動場そのものの代表点ではない。厳密な敷地内位置を意味しない。

## Accessibilityモデル

各人口メッシュについて、08:00を基準に次の最短所要時間を計算する。

人口100mメッシュ → 徒歩道路NW → GTFS停留所 → 時刻表GTFS → 必要に応じて停留所間徒歩乗換 → GTFS → 徒歩道路NW → 避難先

徒歩のみで避難先へ到達する方が速い場合は徒歩直接経路も候補とする。

比較条件:

- Baseline: 全運行便を利用可能
- Scenario A: 右回り系統 route 11 / 21を利用不能とするD区分Stress Test

## 実計算結果

### 指定緊急避難場所 — 4施設

- Baseline 30分圏人口: 20,789.8079人相当
- Scenario A 30分圏人口: 20,381.2975人相当
- 1分超悪化人口: 1,035.1204人相当
- 人口加重平均所要時間悪化: +0.201分

### 指定一般避難所 — 13施設

- Baseline 30分圏人口: 25,055.4109人相当
- Scenario A 30分圏人口: 25,053.2837人相当
- 1分超悪化人口: 1,375.3316人相当
- 人口加重平均所要時間悪化: +0.230分

### 指定福祉避難所 — 2施設

- Baseline 30分圏人口: 15,090.5726人相当
- Scenario A 30分圏人口: 15,064.1391人相当
- 1分超悪化人口: 981.8614人相当
- 人口加重平均所要時間悪化: +0.230分

閾値人口だけでなく、1分超悪化人口と平均所要時間差を併記する。到達圏人口の差が小さくても、個別メッシュの所要時間が悪化するケースを見落とさないためである。

表示内容:

- Scenario Aで1分超悪化する人口

A1.9では避難所GeoJSONを公開するが、Leaflet地図上で病院／緊急避難場所／一般避難所／福祉避難所を切り替えるUIまでは実装しない。地図表示機能は別Stageとして扱う。

## Limitations

- 大洲市全域ではなく、ぐるりんおおずGTFS停留所bbox周辺の分析である。
- 公式避難所Excelに座標がないため、AccessibilityはOSM位置照合に成功したsubsetを対象とする。
- `parent_feature`では親施設の代表位置を使用しており、運動場等の正確な入口・敷地内位置ではない。
- 人口は令和2年簡易100mメッシュの按分値であり実測100m人口ではない。
- 避難所の収容人数は保持するが、A1.9では容量制約付き配分や満員判定を行わない。
- 避難先までの道路が災害時にも通行可能であると仮定しており、災害被害予測ではない。
- 右回り運休はD区分Stress Testであり、実際の災害時運休確率を意味しない。
