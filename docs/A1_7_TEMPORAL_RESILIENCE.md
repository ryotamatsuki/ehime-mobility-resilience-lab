# A1.7 — Ozu Temporal Resilience

基準日: 2026-08-22

## 目的

A1.6までの08:00固定Accessibilityを終日分析へ拡張し、同じ右回り運休Stress Testでも時間帯によって影響がどの程度変化するかを定量化する。

## 分析条件

- 対象日: 2026-08-21
- 時間帯: 06:00〜21:00
- 間隔: 60分
- 時点数: 16
- 基準地図: 08:00
- 公共交通: 大洲市「ぐるりんおおず」GTFS v5.0
- 徒歩: OSM pedestrian network
- stop-to-stop transfer: 道路NW徒歩10分以内 + 1分buffer
- 人口: 令和2年簡易100mメッシュ人口
- 目的地: 愛媛県公式医療機関台帳と照合済みのOSM病院5施設
- Stress Test: 右回りroute停止（D区分の利用者仮定）

## 成果物

`temporal_profile.json` に16時点それぞれについて以下を保存する。

- Baseline 30/60/90分到達人口
- Scenario A 30/60/90分到達人口
- Baseline / Scenario A 人口加重平均所要時間
- 1分超・5分超・10分超悪化人口
- 30分・60分到達圏損失人口
- 平均所要時間悪化

地図用 `population_access.geojson` は従来との比較可能性を維持するため08:00断面を保持する。

## 実データ結果

16時点を同一runで再計算した結果、1分超悪化人口が最大となるのは11:00だった。

- 11:00 1分超悪化人口: 3,370.5401人相当
- 11:00 平均所要時間悪化: +0.895分
- 最小影響時刻: 06:00
- 06:00 1分超悪化人口: 0人相当
- 08:00 1分超悪化人口: 2,030.3675人相当
- 08:00 平均所要時間悪化: +0.732分

したがって、08:00単独断面だけでは右回り運休の最大影響を過小評価することが確認できた。

## 解釈上の注意

この結果は実災害予測ではない。GTFS時刻表・OSM徒歩網・人口按分値を用いたC区分のAccessibility計算に、D区分の右回り運休仮定を適用したStress Testである。

終日分析は1時間間隔のサンプルであり、連続時間積分ではない。より細粒度の30分・15分分析は計算量と必要性を確認した上で将来拡張する。
