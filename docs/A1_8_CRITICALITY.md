# A1.8 — Ozu Route / Trip Criticality

基準日: 2026-08-22

## 目的

大洲市「ぐるりんおおず」について、どの路線・どの便が利用不能になると病院Accessibilityへの影響が大きいかを、実GTFSとA1.7までの同一モデルで比較する。

## 方法

08:00を基準時刻としてleave-one-out分析を行う。

- active routeを1路線ずつ停止
- active tripを1便ずつ停止
- その他の入力・徒歩乗換・病院目的地・人口は固定
- 各停止ケースで1,840人口メッシュを再計算

順位は合成スコアを使用せず、次の透明な順序とする。

1. 1分超悪化人口の多い順
2. 同値の場合、人口加重平均所要時間悪化の大きい順
3. さらに同値の場合、ID順

これは「故障確率」「利用者数」「復旧コスト」を含む総合重要度ではなく、Accessibilityへの結果感度を示すC区分のCriticalityである。

## 解釈

08:00の病院Accessibilityでは、07:15発のroute 21便が突出して重要である。一方、左回り2routeの単独停止は、この目的地・時刻・指標では最短病院アクセスを悪化させなかった。

これは路線自体が社会的に不要という意味ではない。対象時刻、目的地、人口分布、評価指標を限定した結果であり、他時間帯・避難所・日常移動・実利用者数では順位が変わり得る。
