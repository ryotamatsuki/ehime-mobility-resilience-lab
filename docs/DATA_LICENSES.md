# Data Licenses and Redistribution Gate

調査基準日：2026年8月23日（JST）

## コード

リポジトリのコードはMIT Licenseとする。データの利用条件はコードライセンスから独立し、各データセットの個別条件を優先する。

## OSM

OpenStreetMapの道路抽出物はODbL 1.0の対象として扱う。公開地図にはOpenStreetMapのattributionとODbLへのリンクを常時表示する。抽出日時、Overpassクエリ、対象タグ、取得checksumをmetadataに残す。OSM由来のデータベースを再配布する場合は、ODbLの表示・データベース条件を確認する。

A1ではGTFS停留所bbox + 0.02度の道路・施設をCI実行時だけ取得し、Raw Overpass JSONはGitHubへ固定保存しない。分析結果・小規模な派生成果物にもOpenStreetMap attributionを保持する。

A1.9の避難所位置は、大洲市公式避難所名簿に座標が存在しないため、現在のGTFS分析範囲内で公式施設名と一意に照合できたOSM named featureの位置をB区分として利用する。OSM位置を大洲市の公式座標と表示してはならない。

## 大洲市「指定緊急避難場所・指定一般避難所・指定福祉避難所」

公式データページ：<https://www.city.ozu.ehime.jp/site/opendata/31903.html>

A1.9で利用するExcel：<https://www.city.ozu.ehime.jp/uploaded/attachment/47130.xlsx>

2026年4月1日更新の公式オープンデータで、CC BY 4.0として利用する。公式名簿には施設名、住所、災害種別、電話番号、受入対象者、想定収容人数等が含まれるが、緯度・経度は含まれない。

A1.9では次の利用境界を設ける。

- 公式施設名・住所・収容人数等はA区分の公式属性として扱う。
- 施設位置は公式データ由来ではなく、公式名と一意に照合できたOpenStreetMap named featureをB区分として利用する。
- 曖昧一致・未照合施設は推測座標や外部ジオコーダーで補完せず、Accessibility計算から除外する。
- 「○○高校運動場」等をOSMの親施設「○○高校」位置へ対応させる場合は `parent_feature` と明示し、運動場そのものの正確な代表点とは扱わない。
- 公式市全体件数60/96/20を、現在のGTFS分析範囲における位置照合率の分母として扱わない。公式名簿のみでは分析範囲内施設数を確定できないためである。
- Raw ExcelはCI実行時に取得するが、repository、GitHub Actions artifact、GitHub Pagesへ同梱しない。
- 公開する `shelters.geojson` 等は大洲市公式属性（CC BY 4.0）とOSM由来位置（ODbL 1.0）を組み合わせた派生成果物であることを明示する。

## 愛媛県 医療機関の報告内容（基本情報）

公開ページ：<https://www.pref.ehime.jp/page/50405.html>

A1.5では愛媛県医療対策課が公開する2026年8月1日時点の医療機関基本情報Excelを、病院の現行性を確認する公式Gateとして利用する。

このExcelは通常の愛媛県公式Webページに掲載されており、本プロジェクトでは愛媛県オープンデータカタログのCC BYデータであるとは扱わない。再利用・再配布が明示的に許可されたデータであると推定しない。

リスク回避のため、A1.5では次を必須とする。

- Raw Excelをrepositoryへcommitしない。
- Raw ExcelをGitHub Actions artifact / GitHub Pagesへ含めない。
- 公式台帳の行、公式名称、住所、機関コード、公式緯度経度を公開GeoJSONへコピーしない。
- Actions logへ施設行を出力しない。
- ExcelはCI実行中に一時取得し、OSM hospitalが現行公式病院と対応するかの照合にのみ利用する。
- 公開する位置・名称はODbL対象のOSM由来とする。
- 公開成果物には最小限の照合フラグ・照合距離だけを保持する。

今後、公式名称・公式座標等を直接Web表示する場合は、その前に個別の再利用条件または利用許諾を確認する。

## 国土数値情報・人口メッシュ

利用規約と個別データページを確認し、R6 500m将来人口メッシュは掲載されたCC BY 4.0条件に従う。出典、データ名、取得日、加工内容を表示する。公開版は必要最小限の集約成果物とし、原ZIPの再配布可否は個別条件を確認する。

## 道路交通センサス

国土交通省の公開ページ、利用規約、個別ファイルの表示条件に従う。CSVの観測値はA、道路リンクへの対応付けはB、配分・アクセシビリティはCとして保存する。出典と元ページをmanifestに含める。

## e-Stat

e-Stat利用規約に従い、統計名、表番号、基準年、取得日、加工内容を記録する。APIキーや利用者固有の認証情報は保存しない。表の値を自動車交通量、実測OD、個別施設在庫と誤表示しない。

## ODPT GTFS / GTFS-Realtime

ODPTの利用者登録、開発者規約、基本ライセンス、データセット個別条件を確認してから取得・公開する。条件が未確認の生GTFS ZIPと、復元可能な派生データをGitHubへ含めない。許可された場合も、取得元、feed version、取得日時、checksum、出典表示、公開対象フィールドを記録する。GTFS-Realtimeは鮮度と取得日時を明示し、長期キャッシュを公開しない。

## 愛媛県オープンデータ

愛媛県標準利用規約を確認し、原則CC BY 4.0として扱う。ただしデータセット個別条件、第三者権利、座標付与の根拠が優先される。加工した場合は、元データ、加工日、変換内容、加工者を表示する。

通常の県公式Webページ掲載物を、オープンデータカタログ掲載物と同一条件だと推定してはならない。

## 港湾・倉庫・防災施設

港湾GIS、Project LINKSの倉庫データ、現行の災害拠点病院一覧は、個別ライセンス・現行性・再配布可否を確認するまで公開入力にしない。施設一覧は在庫量や業務能力を意味しない。備蓄数量の表示は公式資料に記載された範囲だけに限定する。

## Phase B GIS

愛媛県新地震被害想定GISは、掲載条件がCC BY-NC-NDであり、許諾取得前の加工・派生・Web表示・GitHub公開を禁止する。本リポジトリには原データ、派生データ、ハザード値付与道路を含めない。

## 公開判定

公開可能性が不明なものは、data/metadata/datasets.jsonで external_input または blocked とし、public bundleへコピーしない。公開前にライセンス監査を実行し、出典表示がmanifestとWeb画面の両方に存在することを確認する。
