# Data Licenses and Redistribution Gate

調査基準日：2026年8月22日（JST）

## コード

リポジトリのコードはMIT Licenseとする。データの利用条件はコードライセンスから独立し、各データセットの個別条件を優先する。

## OSM

OpenStreetMapの道路抽出物はODbL 1.0の対象として扱う。公開地図にはOpenStreetMapのattributionとODbLへのリンクを常時表示する。抽出日時、Overpassクエリ、対象タグ、取得checksumをmetadataに残す。OSM由来のデータベースを再配布する場合は、ODbLの表示・データベース条件を確認する。

A1.1ではGTFS停留所bbox + 0.02度の道路・施設をCI実行時だけ取得し、Raw Overpass JSONはGitHubへ固定保存しない。分析結果・小規模な派生成果物にもOpenStreetMap attributionを保持する。

## 大洲市「ぐるりんおおず」GTFS

公式データページ：<https://www.city.ozu.ehime.jp/site/opendata/44871.html>

2026年4月1日更新の公式ページでCC BY 4.0を確認した。A1.1で利用するfeed version 5.0は2026-04-01〜2027-03-31が有効期間である。

A1.1では生GTFS ZIPをリポジトリへ再配布せず、CI実行時に公式URLから取得する。分析成果物には大洲市を出典として記録する。将来、生GTFS自体を公開bundleへ同梱する場合は、その時点の公式利用規約・出典表示要件を再確認する。

## 令和2年簡易100mメッシュ人口

提供ページ：<https://gtfs-gis.jp/teikyo/>

提供者は、令和2年国勢調査250mメッシュ人口を建物面積等で100mへ簡易按分したデータについてCC BYと明記している。

これは100mセルの実測人口ではない。A1.1ではB区分の加工統計として扱い、提供元と「簡易按分値」であることを明記する。Raw ZIPはCI実行時に取得し、GitHubへ固定保存しない。

## 国土数値情報・人口メッシュ

利用規約と個別データページを確認し、R6 500m将来人口メッシュは掲載されたCC BY 4.0条件に従う。出典、データ名、取得日、加工内容を表示する。公開版は必要最小限の集約成果物とし、原ZIPの再配布可否は個別条件を確認する。

## 道路交通センサス

国土交通省の公開ページ、利用規約、個別ファイルの表示条件に従う。CSVの観測値はA、道路リンクへの対応付けはB、配分・アクセシビリティはCとして保存する。出典と元ページをmanifestに含める。

## e-Stat

e-Stat利用規約に従い、統計名、表番号、基準年、取得日、加工内容を記録する。APIキーや利用者固有の認証情報は保存しない。表の値を自動車交通量、実測OD、個別施設在庫と誤表示しない。

## ODPT GTFS / GTFS-Realtime

ODPTの利用者登録、開発者規約、基本ライセンス、データセット個別条件を確認してから取得・公開する。条件が未確認の生GTFS ZIPと、復元可能な派生データをGitHubへ含めない。許可された場合も、取得元、feed version、取得日時、checksum、出典表示、公開対象フィールドを記録する。GTFS-Realtimeは鮮度と取得日時を明示し、長期キャッシュを公開しない。

## 愛媛県オープンデータ

愛媛県標準利用規約を確認し、原則CC BY 4.0として扱う。ただしデータセット個別条件、第三者権利、座標付与の根拠が優先される。加工した場合は、元データ、加工日、変換内容、加工者を表示する。

## 港湾・倉庫・防災施設

港湾GIS、Project LINKSの倉庫データ、現行の災害拠点病院一覧は、個別ライセンス・現行性・再配布可否を確認するまで公開入力にしない。施設一覧は在庫量や業務能力を意味しない。備蓄数量の表示は公式資料に記載された範囲だけに限定する。

## Phase B GIS

愛媛県新地震被害想定GISは、掲載条件がCC BY-NC-NDであり、許諾取得前の加工・派生・Web表示・GitHub公開を禁止する。本リポジトリには原データ、派生データ、ハザード値付与道路を含めない。

## 公開判定

公開可能性が不明なものは、data/metadata/datasets.jsonで external_input または blocked とし、public bundleへコピーしない。公開前にライセンス監査を実行し、出典表示がmanifestとWeb画面の両方に存在することを確認する。
