# Competition Summary

## 解決する課題

交通が止まった後に情報を見るだけでは、公共交通、道路、物流、救援物流の代替性を平時に確認できない。本プロダクトは、愛媛の交通ネットワークを意図的に止め、どの人・移動・物のアクセスが変わるかを定量比較する。

## 公共交通オープンデータを中心にする理由

公共交通は、停留所、路線、便、時刻、運行日を持つため、道路の存在表示を越えて、実際の到達可能性を計算できる。GTFSが未取得の事業者を補完せず、事業者ごとの提供範囲とライセンスを表示すること自体をデータ透明性の一部とする。

## 想定ユーザー

防災危機管理、交通政策、道路管理、公共交通事業者、港湾・物流、防災拠点運用の担当者である。専門GISの操作を前提にせず、平常時を見る、止めてみる、何が困る、どう戻す、どこが重要の順で使えるUIを設計する。

## 独自性

- 公共交通を中心に、道路、自動車、物流、救援物流を同一ネットワーク上で比較する
- 市町村間の観測通勤・通学総量と、細粒度Synthetic ODを分離する
- 任意リンクの閉鎖、容量低下、速度低下、路線停止をユーザー仮定として保存する
- Critical Linkを、アクセス損失、旅行時間、物流・救援経路の相対変化で説明する
- データ版、モデル版、推計区分、出典、生成git_shaを結果から追跡する

## 現在の実証範囲

A1.12時点の公開実証は、大洲市「ぐるりんおおず」の実GTFSを中心に、OSM、100m人口、公式確認した病院・避難所データを組み合わせた公共交通Stress Testである。

現在、実データで確認できる主な分析は以下である。

1. Baseline / 右回り運休のAccessibility比較
2. 06:00〜21:00の時間帯別Accessibility
3. Route / Trip Criticality
4. Time-dependent Criticality
5. 病院・指定緊急避難場所・指定一般避難所・指定福祉避難所への到達性
6. all / 65+ / 75+ / 85+ の年齢層別Equity分析

道路、鉄道、航路、港湾、物流等は長期構想として保持するが、実装・実証されていない機能を現在の完成機能として扱わない。

## Synthetic ODと検証

県内詳細自動車ODを公式値として扱わず、国勢調査市町村OD、人口・雇用分布、道路交通センサス、広域ODを制約に用いる。非通勤、貨物、車両換算はC区分とし、観測リンクの80%校正と20%holdoutを分離する。

## 行政実務での利用

会議前に、対象施設や交通機能の停止条件をプリセットから選び、影響人口、公共交通アクセス、旅行時間等を確認する。結果の数字をクリックすると、入力版、モデル、パラメータ、推計区分を確認できる。将来の道路・物流機能は、実データとモデル検証が完了した範囲から段階的に有効化する。

## 制約

本プロダクトは実被害予測、災害対応指示、企業在庫推計、完全な企業間サプライチェーン、個人移動履歴、リアルタイム災害判断を提供しない。GTFSの提供範囲、統計の基準年、施設の現行性、道路リンク対応、Synthetic ODの仮定を明示する。

## 継続運用とPhase B

更新センターのcandidate、validated、active、archivedを使い、非エンジニアでもデータ更新とrollbackを行えるようにする。Phase Bの公式ハザードGISは、許諾確認と公開条件がPASSになるまで実装しない。

## 審査時の一文

災害が起きたときに見るアプリではなく、災害が起きる前に「交通が止まった愛媛」を何度も試しておくためのシミュレーション基盤である。
